 Lab Session 5: Modules, Visibility & Workspaces

This directory contains the solutions for **Lab Session 5**, focusing on organizing growing Rust projects into multi-file architectures using modules (`mod`) and visibility keywords (`pub`).

## 📝 Exercises & Implementation Details

* **Exercise A — Declaring Submodules:** 
  Splits functionality into dedicated sub-files within `src/` and exposes them to `main.rs`.
* **Exercise B — Controlling Visibility:** 
  Uses `pub`, `pub(crate)`, and private module boundaries to encapsulate internal implementation details.
* **Exercise C — Multi-file Modular Architecture:** 
  Demonstrates importing items across nested modules using relative (`super::`) and absolute (`crate::`) path resolution.
