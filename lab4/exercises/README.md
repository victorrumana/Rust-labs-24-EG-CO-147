# 🧪 Lab Session 4: Collections & Iterators

This directory contains the solutions for **Lab Session 4**, exploring Rust standard library collections (`Vec`, `HashMap`) and functional sequence processing via `Iterator`.

## 📝 Exercises & Implementation Details

* **Exercise A — Vector Operations:** 
  Demonstrates dynamic array storage using `Vec<T>`, including pushing, popping, slicing, and iterating over mutable references.
* **Exercise B — Frequency Counting with `HashMap`:** 
  Implements a word frequency counter utilizing `HashMap` entry APIs (`entry().or_insert()`).
* **Exercise C — Custom Iterators & Functional Adapters:** 
  Uses iterator chain adapters (`map`, `filter`, `fold`, `collect`) for concise collection processing.
